# PERFECT HUMAN — 디스토피아 방탈출

2060년, 30년 만에 냉동 수면에서 깨어난 피험자의 이야기.
사진·동영상·음악으로 스토리가 진행되고, 각 장면의 검사(퀴즈)를 통과해야 다음으로 넘어갈 수 있습니다.
육성 게임처럼 **상태창**(이름, 일시·위치·상태·칭호, 시스템 로그)이 함께 표시됩니다.
빌드 도구 없이 HTML/CSS/JS만으로 동작합니다.

## 실행

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

(`index.html`을 더블클릭해도 열리지만, 동영상·음악은 로컬 서버로 여는 편이 안정적입니다.)

## 내 스토리로 바꾸기

1. 파일을 넣습니다: 사진 → `assets/images/`, 동영상(mp4) → `assets/videos/`, 음악(mp3) → `assets/music/`
2. `story.js`를 수정합니다. 파일 맨 위에 쓰는 법이 정리되어 있습니다.

```js
lines: [
  "나레이션",
  { speaker: "연구원", text: "{name}님, 정신이 드세요?" },          // {name} → 플레이어 이름
  { system: "[SYSTEM] 해동 완료", effect: "alarm" },                 // 시스템 메시지 + 연출
  { speaker: "연구원", text: "...", info: { 상태: "충격" } },        // 상태창 정보 변경
],
quiz: { title: "출입문 잠금장치", image: "assets/images/luna-card.svg", question: "HUMAN = ?", answer: ["0821130114"], numeric: true, hint: "..." },
```

## 동작 규칙

- 대사를 모두 넘기면 검사(퀴즈)가 나타나고, **통과하기 전까지 다음 버튼이 잠겨 있습니다.**
- 퀴즈가 없는 장면은 대사를 다 보면 바로 다음으로 넘어갈 수 있습니다.
- `requireWatch: true`인 동영상은 끝까지 봐야 버튼이 열립니다.
- 화면 연출: `shake`(흔들림), `glitch`(화면 깨짐), `flash`(번쩍임), `alarm`(경보음 + 붉은 빛)
- 음악 파일이 없으면 낮게 웅웅거리는 기본 배경음이 자동으로 재생됩니다.
- 대화창 클릭 또는 Space/Enter로 대사를 넘깁니다. 진행 상황은 자동 저장('이어하기').

> 참고: 정답이 `story.js`에 그대로 들어 있어서 페이지 소스를 열면 볼 수 있습니다.
